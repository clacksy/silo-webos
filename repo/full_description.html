Silo TV

Unofficial client for LG webOS · MIT · not affiliated with Silo Media L.L.C.

A TV client for Silo, the self-hosted media server. It speaks Silo's Jellyfin-compatible API, so it works with the server you already run — this is the front end only.

What it does

  • Quick Connect sign-in (approve a six-digit code from your phone) or username#Profile with a password
  • Continue watching, Next up, recently added, favourites, and profiles
  • Library browsing with sort, filter, genre and A–Z jump
  • Seasons and episodes, with automatic next-episode playback
  • Subtitles read straight from the file for embedded tracks, with size and style options
  • Audio and subtitle track pickers, multi-version titles, resume and progress shared with Silo's apps

Before you install

You need a rooted LG TV with Homebrew Channel, and your own Silo server with third-party access enabled. Have Silo's Jellyfin-compatible address ready — it is usually different from the web UI address.
